IPA Africa Learning: clickable prototype (version 1.1)
Institute of Parliamentary Affairs Africa, October 2026

HOW TO OPEN
  Double-click index.html (Chrome, Edge or Firefox). No internet is needed, except for the optional live AI mode.
  To use it on phones and tablets, host this folder on a web server.

HOW TO SIGN IN
  Use a participant ID or staff ID and password from the private workbook
  "IPA-Africa-prototype-demo-accounts.xlsx". The workbook is NOT part of this folder; keep it private.
  The sign-in page also has "Sample participant" and "Sample facilitator" buttons for quick demonstrations.

WHAT IS INSIDE
  275 demo accounts (208 participants from 14 countries, plus facilitators, programme directors,
  sponsor liaisons, helpdesk officers and administrators); 46 course books with canonical page numbers;
  quizzes; practice questions; assessments; course discussions; cohort networks; certificates; an AI study assistant.

DATA
  All activity is stored in this browser's local storage only. Profile > "Reset the whole demo" clears it.
  People, course-book text and questions are fictional samples.
